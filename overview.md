# Cybersecurity Risk Assessment Framework for Small Businesses

This repository contains the complete implementation of a web-based cybersecurity risk assessment framework for Small and Medium Enterprises (SMEs), aligned with the NIST Cybersecurity Framework (CSF).

## Directory Structure
- `backend/`: Node.js Express API server, risk calculation algorithms, mitigation engine, and SQLite database storage.
- `frontend/`: Interactive responsive web application with risk assessment wizard, charts, 5x5 risk matrix, risk register, and report generator.
- `database/`: SQLite schema and data persistence files.
- `tests/`: Automated test suite for risk scoring, classification, and NIST mapping.
- `docs/`: Academic documentation, system design, and presentation slides.
